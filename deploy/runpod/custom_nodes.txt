# ComfyUI に追加で入れる custom node の一覧（entrypoint.sh が読む）。
#
# 行の形式:  <git-url> <commit-ish>
#   git-url   … clone する URL
#   commit-ish… checkout するコミットハッシュ or タグ（**必ず固定する**。
#               ブランチ名を書くと Pod を作り直すたびに中身が変わってしまう）
#
# 空行と '#' から始まる行は無視される。clone 先は
# /workspace/ComfyUI/custom_nodes/<リポジトリ名> で、既にあるものは飛ばす
# （＝ 2 回目以降の起動では何もしない）。requirements.txt があれば pip install する。
#
# --------------------------------------------------------------------------
# 既定で入れるのは、MiniMax H3 動画の補正（SPEC §3.1 の fast_derope /
# face_detail / anime_cadence。どれも既定 off）が使う 4 パックだけ。補正を使わない
# なら消してもよい（アプリは off のままなら呼ばない）。
#
# workflow/ のテンプレートが使うノード（ResolutionSelector / CustomCombo /
# ComfySwitchNode / MiniMaxH3 系（MiniMaxH3SigmaShift・MiniMaxH3LatentUpscaleWithModel
# を含む）/ MoGe 系 / LatentUpscaleModelLoader / ModelAttentionBackend /
# BlockSparseAttention / TextGenerateV2 / ResizeImagesByLongerEdge / WanDancer 系 /
# Video Slice / P-H3-Image の PH3ImageConditioning・StringFormat・BatchImagesNode・
# ResizeAndPadImage・LoraLoaderBypassModelOnly など）は、ComfyUI 本体 **v0.44.0 以降**に**本体同梱（comfy_extras）として
# 入っている**ことを前提にしている（Dockerfile の COMFYUI_REF の既定は master）。
# COMFYUI_REF を v0.44.0 より古いタグに下げると足りなくなるので、そのときは本体の
# 更新を優先すること。自分で足したワークフローが外部のノードを要求する場合だけ
# ここに書き足す。
#
# 本体に代替が無く、ここに書いていない外部ノード（使う場合だけ自分で足す）:
#   - SpectrumApplyMiniMaxH3（MiniMax H3 の opt）
#   - ComfyUI-H3-Motion-Context / ComfyUI-MiniMaxH3-Contex-Loop（ラテント連続性）
#
# 足りないノードがあるかどうかは、アプリのヘッダーの接続インジケーター
# （GET /api/health）が「missing custom nodes on ComfyUI: …」として教えてくれる。
#
# 例:
#   https://github.com/ltdrdata/ComfyUI-Manager.git  3a1b2c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b
